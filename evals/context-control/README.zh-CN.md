# 上下文与控制配对探针

[English](README.md) | [简体中文](README.zh-CN.md) · [文档目录](../../docs/README.zh-CN.md)

从仓库根目录运行：

```sh
node --import tsx evals/context-control/run.ts --live --runs=3
```

使用已配置模型并计费。输入为合成案例，不含项目文件、私有聊天和密钥。六类案例覆盖双语约束、修订要求、重复、事件等待、有效进展及验证。保留实验共享两次摘要后的历史，开启组追加原始来源；控制实验共享事实，开启组追加策略建议。轮次间交换组顺序。

版本化报告包含配置、样本、正确性、用量、按价估算成本和耗时，摘要共享成本另列。这是消融烟雾测试，不是端到端编码基准；持平只说明没有观察到收益。缓存冷热、小样本、固定模板都限制比较。
